## 🧠 About My Research

My master's thesis built a **multi-task Aspect-Based Sentiment Analysis (MT-ABSA)** framework using a shared RoBERTa encoder, jointly trained on:
- Aspect-level sentiment classification (3-class)
- Binary recommendation prediction

Trained on 100,000 Amazon product reviews across 6 product dimensions.  
Results: **Macro F1: 0.9273 | Accuracy: 0.9380 | AUC: 0.9809 | p = 0.0154** (5-seed statistical validation)  
Outperformed best classical baseline (Logistic Regression) by **6.69 percentage points**.
